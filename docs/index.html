What it does

Multiple editors open one live session and edit the same timeline together. Nobody locks, nobody waits, nobody merges.

Join in seconds

The host starts a session. The guest types the host's address and a name, then clicks Connect. Both editors now work on one cut.

Every movement control, live

Position, Scale, Rotation, Anchor Point and Opacity sync in about a second, both directions.

The timeline itself, live

Rename, trim and move clips. Your partner's timeline follows each change.

See where your partner works

Your partner's pointer and name are drawn live over your own Premiere window.

Know who changed what

A change feed lists each edit with its author: "Bradley set Hero Rotation to 90 (rev 7)".

No broken timelines

If both editors change the same value at once, both machines settle on the same result.

Why we built it

Almost no film is cut by one person, and more teams work from different cities. Yet every pro editing tool treats the timeline as a one-person space.

"It's not currently possible for more than one editor to make changes on the same timeline." : Adobe staff, 2017. Still true.

Writers got Google Docs. Designers got Figma. Developers got live pair programming. Film editors are still waiting for their turn.

  • Save the project file

  • Download and relink media
  • Open it. Now they wait.

How it works

01

Premiere panel

CEP 11 + ExtendScript. Reads the timeline each second, sends what changed, applies what your partner sent.

02

Sync engine

Plain JavaScript with no Premiere calls, tested on its own with node --test.

03

Relay

Node.js + ws on the host laptop. Numbers every edit; the higher revision wins.

04

Live cursor

A PowerShell helper draws a click-through overlay with your partner's pointer and name.

Laptops connect over Tailscale, so it works on any network with internet. If two edits touch the same field, the latest numbered edit wins on both machines.

Try it

You need two Windows laptops with Premiere Pro 22.3.1, and Node.js on the host.

  • Run install.ps1 on each laptop, then restart Premiere.
  • Open the panel: Window > Extensions > Tandem.
  • Connect the laptops with Tailscale.
  • Host: start the relay, then click Host in the panel.
  • Guest: enter the host's address and your name, then click Connect.

Edit something. Your partner's Premiere changes within about a second.
